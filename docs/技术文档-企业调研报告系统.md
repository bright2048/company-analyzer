## 1. 系统概述

本系统是一个企业调研报告自动化生成平台，主要功能包括：

- **公司信息搜索**：支持通过网络公开信息、天眼查API、企查查API三种数据源获取企业信息

- **报告自动生成**：基于LLM技术生成包含公司概况、发展历程、高管团队、市场营销、财务状况、行业竞争、风险提示等多维度的专业分析报告

- **园区企业管理**：支持通过Excel文件批量导入园区企业名单

- **园区匹配分析**：智能分析目标公司与园区的匹配度、上下游企业关系、扩租需求

- **报告导出**：支持Word和PDF格式导出

## 5. 园区匹配分析算法说明

### 5.1 算法概述

园区匹配分析是本系统的核心功能之一，旨在帮助园区招商人员快速评估目标企业与园区的匹配程度。算法采用**LLM智能分析**结合**规则引擎**的混合方式，从多个维度进行综合评估。

### 5.2 分析维度

#### 5.2.1 匹配度评分（Match Score）

**评分范围**：0-100分

**评分因素**：

| 因素 | 权重 | 说明 |
| --- | --- | --- |
| 行业契合度 | 30% | 目标企业行业与园区主导产业的匹配程度 |
| 产业链关联 | 25% | 与园区现有企业的上下游关系强度 |
| 规模适配性 | 20% | 企业规模与园区定位的匹配程度 |
| 发展阶段 | 15% | 企业发展阶段与园区服务能力的匹配 |
| 区位需求 | 10% | 企业业务对区位的需求程度 |

#### 5.2.2 入驻可能性评估（Entry Possibility）

**评估等级**：高 / 中 / 低

**判断逻辑**：

```
入驻可能性 = f(匹配度评分, 企业扩张意愿, 现有布局, 政策吸引力)

高：匹配度≥70 且 有明确扩张需求 且 无区域布局冲突
中：匹配度50-70 或 扩张意愿不明确
低：匹配度<50 或 已有区域布局 或 行业不匹配
```

#### 5.2.3 上下游企业识别（Upstream/Downstream Companies）

**识别方法**：

1. **行业关联分析**：基于目标企业的行业属性，识别产业链上下游行业

1. **业务范围匹配**：分析目标企业经营范围与园区企业经营范围的交集

1. **供应链推理**：基于LLM对行业知识的理解，推理潜在的供应商和客户关系

**示例**：

```
目标企业：某新能源汽车零部件公司
行业：汽车零部件制造

上游企业识别：
- 原材料供应商（钢铁、塑料、电子元器件）
- 设备供应商（加工设备、检测设备）

下游企业识别：
- 整车制造商
- 其他零部件集成商
- 汽车维修服务商
```

#### 5.2.4 扩租需求预测（Expansion Need）

**预测等级**：高 / 中 / 低

**预测因素**：

| 因素 | 指标 | 说明 |
| --- | --- | --- |
| 业务增长 | 近期融资情况、营收增长 | 融资后通常有扩张需求 |
| 人员扩张 | 招聘信息、员工增长 | 人员增加带来空间需求 |
| 产能需求 | 订单增长、产能利用率 | 产能不足时需要扩租 |
| 战略布局 | 新业务线、区域扩张计划 | 战略调整带来空间需求 |

### 7.5 迁移注意事项

1. **API兼容性测试**：切换LLM服务后，建议先生成几份测试报告，确认输出质量符合预期

1. **存储迁移**：如果已有报告文件存储在原有服务中，需要进行数据迁移

1. **网络延迟**：选择与服务器同地域的云服务，可以显著降低延迟

1. **备用方案**：建议配置多个LLM服务作为备用，当主服务不可用时自动切换

1. **合规要求**：如果有数据合规要求（如等保），需要选择符合要求的云服务商
