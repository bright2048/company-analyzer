# 鲲鹏Token汇聚平台 - 产品需求文档 (缩略版)

## 一、 项目定位与商业模式

### 1.1 项目定位
**鲲鹏Token汇聚平台**是一个专业的、高可用的大模型API聚合消费平台。平台向下聚合国内及国际主流大模型厂商（如DeepSeek、阿里通义、月之暗面、智谱AI、字节跳动、OpenAI等）的Token资源，向上为企业、开发者及个人用户提供**统一接口、弹性计费、自动故障转移、多模态支持**的AI调用网关。

### 1.2 商业模式
平台通过**批量采购、算法路由、多级套餐与增值服务**实现盈利：
1. **采购差价**：通过大批量采购大模型厂商Token获得超低折扣，在零售给最终用户时获取差价。
2. **多级套餐溢价**：通过不同额度、不同有效期的套餐，锁定用户资金，提高沉淀资金收益。
3. **企业增值服务**：为企业客户提供专线加速、多组织管理、私有化部署、数据合规审计等增值服务。

## 二、 核心功能模块

### 2.1 供应商接入层 (向下聚合)
平台全面适配国内主流及国际前沿大模型厂商协议，并统一封装为标准OpenAI接口格式：

| 供应商名称 | 核心代表模型 | 协议适配模式 | 特殊功能支持 |
| :--- | :--- | :--- | :--- |
| **DeepSeek** | DeepSeek-V3.2, R1, V4 | OpenAI兼容 | 上下文缓存（Context Caching）、FIM补全 |
| **月之暗面 (Kimi)** | Kimi K2.5, K2.6 | OpenAI兼容 | 256k-1M超长上下文、Thinking模式 |
| **阿里通义 (Qwen)** | Qwen3-Max, Qwen3.5-Plus | DashScope OpenAI兼容 | 1M超长上下文、多模态输入 |
| **智谱AI (GLM)** | GLM-4-Flash, GLM-4-Plus | OpenAI兼容 | 中文学术场景优化、多模态支持 |
| **字节跳动 (豆包)** | Doubao-Pro, Doubao-Lite | 火山引擎 OpenAI兼容 | 极致高并发（QPS）、极低单价 |
| **百度文心 (ERNIE)** | ERNIE-4.0-Turbo | OAuth2 动态Token鉴权 | 百度企业级生态、行业大模型 |
| **讯飞星火 (Spark)** | SparkDesk-V4.0 | WebSocket转HTTP适配器 | 语音交互、行业定制能力 |
| **OpenAI / Anthropic** | GPT-4.1, Claude Sonnet 4.6 | 标准协议 / 境外专线中转 | 顶级推理与Agent编程能力（SWE-bench 72.7%） |

### 2.2 统一调用网关 (向上消费)
1. **统一协议格式**：支持标准的 `POST /v1/proxy/chat/completions`，完美兼容OpenAI SDK。
2. **流式响应 (SSE)**：支持 `stream: true` 模式，通过Server-Sent Events实现打字机效果，首字延迟控制在300ms以内。
3. **多模态与辅助接口**：支持 `embeddings`、`images/generations`、`audio/transcriptions` 等接口。
4. **智能路由与故障转移**：按优先级、健康度、延迟和成本，自动在备用通道间无缝切换，实现用户无感知故障转移。

### 2.3 钱包与计费体系
1. **精度控制**：系统内部统一使用**微美元 (Micro-USD, $1 \times 10^{-6}$ USD)** 作为计费精度，避免浮点数计算误差。
2. **多级套餐购买**：
   - **入门包**：¥29 $\rightarrow$ $4 USD额度 (30天有效期)
   - **基础包**：¥99 $\rightarrow$ $14 USD额度 (30天有效期)
   - **专业包**：¥399 $\rightarrow$ $56 USD额度 (30天有效期)
   - **企业包**：¥1499 $\rightarrow$ $210 USD额度 (365天有效期)
3. **优惠券核销**：支持固定额度券、消费折扣券、赠Token券，支持防刷与限次核销。

### 2.4 企业级控制台 (Console)
1. **开发者中心**：API Key自助管理（支持创建多个Key、设置Key级额度和限速）、在线接口测试。
2. **用量可视化**：提供按天、按模型、按Key聚合的消费看板，支持图表展示。
3. **组织与团队管理**：支持企业管理员邀请成员，共享同一钱包余额，并为不同成员分配配额。
4. **财务与合规**：支持对公转账充值、自动生成增值税电子发票。

## 三、 非功能性需求与安全合规

### 3.1 性能与可用性指标
* **并发性能**：网关层设计QPS $\ge 5000$，单用户默认限流（根据套餐级别动态调整，入门级20次/分钟，企业级不限流）。
* **响应时延**：网关自身处理时延 $\le 10\text{ms}$，首字时延（流式） $\le 300\text{ms}$（依赖上游）。
* **系统可用性**：SLA $\ge 99.95\%$，通过多区域部署与自动健康检查保障。

### 3.2 安全与隐私保护
* **密钥安全**：所有供应商API Key使用AES-256-GCM加密存储，密钥管理接入HashiCorp Vault。
* **数据脱敏**：默认不存储用户请求的Prompt和Response内容，仅记录Token数、耗时等计费元数据。
* **防刷风控**：对注册、优惠券核销接口接入人机校验（如Cloudflare Turnstile），防止恶意刷取余额。

### 3.3 法律与内容合规
* **内容安全过滤**：网关层内置敏感词过滤和违规内容检测（接入国家网信办合规的内容安全API），拦截政治、色情、暴力等不合规输入输出。
* **资质合规**：平台需申请并具备**增值电信业务经营许可证（ICP、EDI）**，确保在国内合法合规运营。

## 四、 迭代规划

### 4.1 Phase 1：核心网关与供应商适配 (1-2个月)
* 实现Go高性能统一网关，适配DeepSeek、Qwen、Kimi、OpenAI等核心协议。
* 建立多级路由与自动故障转移机制，支持流式响应（SSE）。
* 完成数据库基础设计（PostgreSQL），实现基础钱包计费（行锁原子操作）。

### 4.2 Phase 2：企业级控制台与支付合规 (2-3个月)
* 推出Next.js 15开发的开发者控制台，支持多API Key管理、用量看板。
* 集成微信/支付宝/对公转账支付，支持发票自动开具。
* 完善优惠券系统与注册风控。

### 4.3 Phase 3：企业级特性与生态建设 (3-6个月)
* 引入Redis缓存层，支持高并发下的Token余额缓存和限流。
* 推出组织/团队协作功能，支持额度分配。
* 接入Prometheus+Grafana监控体系，实现智能毛利分析与异常告警。
